# Reforge
## Reforge Illustration

<structure id="../../structures/tofus_thinking/reforge_structure.nbt"/>
This block can accommodate items, either by right clicking or automated input, and completed items can be output
The material can be placed in the fish tank above the item or directly used as item entity. If fluid is needed, it can only be in the fish tank
The block needs to have stable prismarine bricks in any two of the four directions, and be impact by an anvil within 10 ticks to complete the recasting process, which can give the item new componet
