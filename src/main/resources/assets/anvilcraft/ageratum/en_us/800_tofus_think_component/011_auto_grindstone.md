# Auto Grindstone

>It might be compatible with certain special grinding wheel operations, sort of

<row halign="center">
<item id="anvilcraft_tofus_thinking:auto_grindstone"/>
</row>

- The grindstone has two input slots, so you can automatically input from the top slot to the upper column and from the side slot to the lower column
- There are two output columns, which can be output in any direction
- It cannot be manually entered, but the items inside can be manually removed
- Upon receiving a redstone signal, it functions similarly to a dispenser
- After execution, the gained experience will be stored and converted into <ref item="anvilcraft:exp_gem"/> whenever possible
- Can store up to one set of experience gems and temporarily store the experience from another set of experience gems. Any excess will directly generate experience orbs
