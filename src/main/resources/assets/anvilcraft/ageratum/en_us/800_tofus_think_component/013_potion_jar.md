# Potion Jar

>WHAT IS PILL?

<row halign="center">
<item id="anvilcraft_tofus_thinking:potion_jar"/>
</row>

- Right-click on the potion in the GUI interface to fill it (250MB), or in automatic mode, Shift-right-click to fit as many identical potions as possible into the inventory
- Each consumption consumes 50MB by default, and automatic consumption can be executed in the inventory or the Ender Chest
- When the infusion exceeds the maximum capacity, brewing of single-effect potions that last for more than 30 seconds will no longer consume it
