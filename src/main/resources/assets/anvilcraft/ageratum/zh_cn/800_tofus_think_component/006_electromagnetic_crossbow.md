# 电磁弩

<item id="anvilcraft_tofus_thinking:electromagnetic_crossbow"/>

> 这其实是铁砧工艺的一个废案

- 基本能力等同弩
- 可装填一组弹药，如果副手物品与状态弹药相同且不是不消耗的弹药，则可尝试继续填入
- 每次射击冷却0.5s，除了烟花外的弹射物速度为80m/s
- 自动寻找物品栏的箭矢装填，除非副手有其他可装填物品
- 可装填金属粒或者宝石作为弹药，金属粒的质量决定伤害，部分类型具有额外效果
- 可自然附魔弩的所有附魔并响应弓的附魔，除此之外，无限附魔会让铁粒装填时不消耗，忠诚会让落地的可被拾取的普通箭矢或者药水箭矢自动返回到玩家身边
- 也可发射雪球，鸡蛋，末影珍珠，药水，火焰弹等，但多重射击只会对箭矢，烟花，宝石，金属粒，雪球，投掷药水，火焰弹生效

| 弹药 | 特殊效果 |
| :---: | :---: |
| 银粒 | 对亡灵生物伤害增加50% |
| 诅咒金粒 | 对目标施加虚弱II(00:10) |
| 余烬金属粒 | 目标增加额外的10秒燃烧时间 |
| 钚/铀粒 | 对目标施加凋灵II(00:10) ，伤害随目标盔甲覆盖率降低而增加|
| 黄玉 | 在命中目标处释放九雷轰顶 |
| 蓝宝石 | 冻结八格内生物，施加冰冻伤害并造成缓慢III(00:15) |
| 红宝石 | 点燃八格内生物，施加火焰伤害并损坏其装备 |
