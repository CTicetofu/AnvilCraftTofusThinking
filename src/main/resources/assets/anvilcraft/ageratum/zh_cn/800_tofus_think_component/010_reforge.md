# 重铸
## 重铸图示

<structure id="../../structures/tofus_thinking/reforge_structure.nbt"/>
该方块可容纳物品，右键或者自动化输入均可，完成的物品可以被输出
材料放置在该物品上方一格的鱼缸中，也可直接作为掉落物形式，如果需要流体，则只能是鱼缸
需要该方块四个方向中任意两个方向有坚固海晶石砖，并在10tick内分别受到铁砧砸击以完成重铸，重铸可赋予物品新的属性

同时添加了一些新的组件

- 致密：提升10%盔甲和保护的保护性能->计算该部分减伤时额外减去计算前伤害的10%，但不能超过剩余伤害的一半，即如果你的盔甲本次达到了80%减伤，则变为90%，但通过什么方式已经达到90%，则为95%
- 抗毒：减少80%大多数负面效果时间，一半概率免疫（这里是太长而没有写下的内容：如果减少后小于2秒，则直接免疫）
- 重击：增加50%暴击伤害
- 亘古：作为物品实体时，免疫绝大多数伤害，不会随时间消逝
