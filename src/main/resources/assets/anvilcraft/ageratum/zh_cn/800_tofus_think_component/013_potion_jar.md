# 药水罐

>药片是什么东西

<row halign="center">
<item id="anvilcraft_tofus_thinking:potion_jar"/>
</row>

- 在GUI界面右键药水以灌注（250MB），或者在自动模式下Shift右键以尽可能装下物品栏所有相同药水
- 每次饮用默认消耗50MB，在物品栏或者末影箱时可执行自动饮用
- 灌注当超过最大容量时，对于超过30s的可酿造的单一效果药水不再消耗
