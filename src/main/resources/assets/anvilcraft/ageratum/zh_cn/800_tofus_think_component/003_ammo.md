# 诅咒雪球

>为什么我们不能把诅咒金糊对面脸上呢
>>你是不是之前在雪球里掺黑曜石那个？！


<item id="anvilcraft_tofus_thinking:curse_snowball"/>

- 对命中目标施加虚弱，缓慢，饥饿，诅咒，微缩
- 诅咒会抑制回血
- 微缩会降低生物体型

<tip>
也许某些生物缩小后可以被<ref item="anvilcraft:resin_block"/>抓走？
</tip>

# 爆破箭

>别把你家也炸了


<item id="anvilcraft_tofus_thinking:explosion_arrow"/>

- 若未启用破坏掉落物，则其爆炸会尽可能保留方块（如同默认配置的TNT）
- 不会炸毁矿物
- 对爆炸抗性小于100的方块，计算爆炸抗性时 * 0.01，否则 -99
