# 自动砂轮

>可能兼容某些特别的砂轮操作，大概吧

<row halign="center">
<item id="anvilcraft_tofus_thinking:auto_grindstone"/>
</row>

- 砂轮本身有两个输入槽，因此你可以从上方自动输入到上方栏，从侧面输入到下方栏
- 有两个输出栏，任意方向都可输出
- 不能手动输入，但可以手动取出里面的物品
- 收到红石信号工作，类似发射器
- 执行后会存储产生的经验，并尽可能转化为<ref item="anvilcraft:exp_gem"/>
- 最多存储一组经验宝石和暂存一组经验宝石的经验，超过的部分将直接产出经验球
